# Cats & Owl's Diary 3.0

一款为孩子设计的浏览器绘本冒险游戏。玩家可以扮演小猫 Mimi 或猫头鹰 Owlly，在森林学校、月光湖、苹果谷、森林公路、迷雾沼泽和橡果镇中探索，帮助动物朋友、收集道具、完成知识问答，并逐步解锁新的区域。

> A child-friendly browser adventure where Mimi and Owlly explore storybook worlds, help animal friends, collect items, solve learning challenges, and unlock new areas.

## 游戏简介 / Game Overview

《Cats & Owl's Diary》把探索、任务、轻解谜和小学知识问答放在同一条冒险路线中。每个关卡都有独立场景、限时任务和完成结算；部分章节还包含护送、修复、路线判断或 Boss 挑战。

当前完整版本包含：

- 6 组可玩章节，共 29 个关卡。
- Mimi 与 Owlly 两个可选角色。
- 简单、普通、困难、疯狂四档难度。
- 收集、送达、对话、知识问答、避障、护送、修复和 Boss 等玩法。
- 本地保存的昵称、难度、总积分、最高分、最近 50 次记录和世界完成状态。
- 键盘和触屏操作。

The game currently provides 29 playable levels across six adventures, four difficulty modes, local progress records, and both keyboard and touch controls.

## 适合谁玩 / Intended Players

- 小学阶段的孩子，尤其适合作为四年级难度附近的轻量知识练习。
- 适合家长陪同游玩、阅读剧情并讨论解题思路。
- 适合用于持续优化儿童游戏中的引导、难度、反馈和移动端体验。

游戏不需要注册账号，也不需要联网保存进度。所有记录只保存在当前浏览器的本地存储中。

## 快速开始 / Quick Start

### 环境要求 / Requirements

- Node.js
- 现代浏览器，例如 Chrome、Edge 或 Safari
- 无需安装第三方依赖

### 启动游戏 / Run the Game

在项目根目录运行：

```bash
node server.js
```

然后在浏览器打开：

```text
http://127.0.0.1:5177
```

Run `node server.js` from the project root, then open `http://127.0.0.1:5177`.

为了保证脚本、图片和声音资源按预期加载，建议通过本地服务器进入游戏，不要直接双击 `index.html`。

## 核心玩法 / Core Gameplay

一局的主要流程是：

1. 设置昵称，选择 Mimi 或 Owlly，并选择难度。
2. 从关卡列表或世界地图进入已经解锁的区域。
3. 阅读绘本开场页和当前任务提示。
4. 探索场景，收集任务需要的物品。
5. 靠近角色或任务点，按 `E` 对话、交付或开始挑战。
6. 完成知识问答、修复、护送、路线判断或 Boss 任务。
7. 查看关卡结算、积分、答题和碰撞记录，再继续下一关或重玩。

主要系统包括：

- **探索与收集：** 在地图中寻找苹果、铅笔、木板、橡果等任务道具。
- **对话与交付：** 与 NPC 对话，把正确物品交给指定角色。
- **知识问答：** 包含数学、逻辑、科学、语文、英语和谜语等题型。
- **环境挑战：** 绕开水坑、泥地、灌木、落石和其他障碍。
- **章节任务：** 包括修路牌、修木桥、点灯驱雾、护送小动物和兑换道具。
- **Boss 玩法：** 收集指定道具后攻击，同时躲避 Boss 的范围技能。
- **绘本反馈：** 进入任务和完成关卡时显示对应的故事页。

## 难度系统 / Difficulty

| 难度 | 一般关卡时间 | 障碍碰撞扣时 | 答错扣时 | 时间耗尽 |
| --- | ---: | ---: | ---: | --- |
| 简单 🌱 | 基础时间 × 1.35 | 0 秒 | 0 秒 | 可以继续，完成奖励会降低 |
| 普通 🌼 | 基础时间 × 1.00 | 2 秒 | 3 秒 | 可以继续，完成奖励会降低 |
| 困难 🔥 | 基础时间 × 0.82 | 4 秒 | 6 秒 | 可以继续，完成奖励会降低 |
| 疯狂 👑 | 基础时间 × 0.65 | 6 秒 | 10 秒 | 挑战失败，需要重试 |

橡果镇使用独立的固定时间表：

| 关卡 | 简单 | 普通 | 困难 | 疯狂 |
| --- | ---: | ---: | ---: | ---: |
| 橡果镇邮局 | 130 秒 | 110 秒 | 95 秒 | 80 秒 |
| 寻找丢失的橡果 | 140 秒 | 120 秒 | 105 秒 | 90 秒 |

| 小镇公告板 | 150 秒 | 130 秒 | 115 秒 | 100 秒 |

Higher difficulties provide less time, larger time penalties, and higher completion or remaining-time bonuses.

## 成长、积分与解锁 / Progression, Score and Unlocks

- 完成关卡的基础奖励为 30 分；困难额外增加 15 分，疯狂额外增加 40 分。
- 根据通关时的剩余时间，可获得最多 10、20、30 或 50 分的难度时间奖励。
- 普通、困难等非疯狂难度在时间耗尽后仍可继续，但完成奖励会减半。
- 结算面板会显示本局积分、答对与答错数量、障碍碰撞次数、剩余时间、总积分和最高分。
- 浏览器最多保留最近 50 次游玩记录。
- 完成森林公路后，橡果镇才会解锁。
- 完成橡果镇后，河畔码头会在世界地图中更新为下一步区域；河畔码头的实际关卡仍待开发。

昵称、角色、难度、积分和解锁状态保存在浏览器 `localStorage`。清除浏览器网站数据、更换浏览器或更换设备后，记录不会自动同步。

## 测试 / Testing

运行全部回归测试：

```bash
node --test tests/*.test.mjs
```

当前测试覆盖关卡数据、世界地图、资源回退、移动端布局、问答、难度、积分、迷雾沼泽、森林公路、苹果谷和橡果镇等关键功能。

手动检查建议：

1. 从首页进入游戏，分别测试 Mimi 和 Owlly。
2. 用键盘和触屏按钮完成一次移动、对话、答题和攻击。
3. 依次完成森林公路，确认橡果镇由锁定变为可进入。
4. 完成橡果镇四关，确认世界地图显示河畔码头为下一步区域。
5. 分别检查普通和疯狂难度下的超时行为。
6. 使用手机尺寸检查顶部信息、声音按钮和世界地图按钮是否遮挡。
7. 暂时移走一张非关键图片，确认资源回退不会导致白屏。
