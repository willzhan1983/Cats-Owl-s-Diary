# 河畔码头四关设计

## 目标

在橡果镇之后新增四关 `riverside_dock` 章节，并把橡果镇公告板给出的路线提示作为进入码头的短过场。完成第四关后解锁 `wetland_park`。

## 范围与边界

- 保留现有 `cat` / `owl` 角色、积分、时间、结算、本地历史和世界完成格式。
- 只新增河畔码头规则、关卡、题库、入口和专用运行逻辑；不改变旧章节任务和题库。
- 复用 Dodo、Ruru、Owlly、`boat_paddle.png` 和 `riverside_dock_sign.png`。
- 第一版使用现有水域背景与 Canvas 道具 fallback；缺少新美术时不能白屏。
- 错误操作只按难度扣时间并击退，不扣爱心、不删除关键道具。
- 河畔码头必须通过世界完成状态解锁，不能依赖关卡数组的物理位置。

## 章节流程

1. `riverside_dock_entrance`：按公告板路线顺序选择三个方向标记，清理漂流木并取得通行牌。
2. `riverside_paddle_search`：观察水流，找到可用船桨和救生圈，忽略损坏船桨。
3. `riverside_bridge_repair`：收集短、中、长桥板与码头绳，按长度顺序修复木桥。
4. `riverside_safe_crossing`：确认安全水位和绿色信号，携带包裹到对岸，答对章节题后解锁湿地公园。

每关均有一题 `riversideDockShared` 题目。题目按难度抽取，同一次章节运行的四题不重复，重置当前关卡保持原题，重新进入章节时重新抽取。

## 难度

| 难度 | 路线长度 | 干扰项 | 错误扣时 | 时间缩放重点 |
| --- | ---: | ---: | ---: | --- |
| Easy | 2 | 0 | 0 秒 | 提示常驻、水位窗口宽 |
| Normal | 3 | 1 | 0 秒 | 标准提示和安全窗口 |
| Hard | 3 | 2 | 3 秒 | 路线提示缩短、水位窗口收窄 |
| Crazy | 4 | 3 | 5 秒 | 最短提示、最多干扰、安全窗口最窄 |

固定关卡时间：

- 码头入口：140 / 120 / 105 / 90 秒。
- 寻找船桨：145 / 125 / 110 / 95 秒。
- 修复木桥：155 / 135 / 120 / 105 秒。
- 安全渡河：160 / 140 / 125 / 110 秒。

## 失败恢复

- 路线选择错误时路线进度归零，角色回到安全点。
- 损坏船桨不能进入背包。
- 桥板顺序错误时已放桥板全部退回可拾取状态。
- 水位或信号不安全时不能开始渡河，包裹继续保留。
- 计时结束沿用现有失败和重开流程。

## 验收

- 世界地图显示独立河畔码头入口；仅在橡果镇完成后可进入。
- 四关顺序固定，完成第四关后 `wetland_park` 解锁。
- 四档难度的时间、路线长度、干扰项、扣时和安全窗口均可验证。
- 四关各有一道难度匹配且同章不重复的题。
- 错误路线、损坏船桨、错误桥板和不安全渡河均可恢复。
- 缺少专用背景或道具图片时仍有可玩的 Canvas fallback。
- 完整自动化测试、桌面和手机浏览器冒烟检查通过，console error 为 0。
