# Cats & Owl's Diary 游戏总 README 设计

## 目标

为包含橡果镇的完整游戏版本建立一份根目录 `README.md`，让家长、玩家和后续开发者可以快速了解游戏现状，并以此作为优化清单的入口。

## 文档语言

- 中文为主，便于日常维护和讨论。
- 关键标题、游戏简介、操作和启动方法同时提供英文说明。
- 不逐段重复全部内容，避免 README 过长。

## 内容结构

1. 游戏名称、版本状态和一句话简介
2. 故事背景、目标玩家和主要角色
3. 快速开始与本地运行方法
4. 键盘、触屏和游戏按钮操作
5. 核心玩法循环
6. 世界地图、已实现章节与关卡表
7. 简单、普通、困难、疯狂四档难度
8. 收集、交付、清理、护送、兑换、答题、Boss、积分和解锁机制
9. 当前完整版本与旧工作目录的区别
10. 主要代码、测试和素材目录
11. 自动测试命令
12. 当前已知问题
13. 后续优化建议，按高、中、低优先级整理

## 信息来源

README 只记录当前完整分支中可以从代码、测试和浏览器验收确认的内容：

- `game.js`
- `world-map.js`
- 各章节 `*-map-entry.js`
- 各章节题库
- `acorn-town-rules.js`
- `tests/*.test.mjs`
- 已完成的浏览器运行检查

世界地图中仍属于规划状态的区域必须明确标为“尚未实现”，不能写成可玩关卡。

## 优化清单原则

- 高优先级：影响进入游戏、关卡解锁、手机端操作或导致白屏的问题。
- 中优先级：界面拥挤、引导不清、难度曲线和反馈不足。
- 低优先级：装饰动画、更多音效、成就展示和内容扩展。
- 已确认的手机端顶部 Logo 与按钮重叠问题列入高优先级。

## 验证标准

- 所有关卡名称与 `game.js` 一致。
- 世界和解锁关系与 `world-map.js` 一致。
- 启动命令能够在当前项目运行。
- 测试命令与现有测试目录一致。
- 不出现 `TODO`、`TBD` 或无法确认的完成状态。
- README 中引用的本地相对路径真实存在。
